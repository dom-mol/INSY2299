When SUM does nothing

Some people use SUM where it isn’t needed, e.g. =SUM(C8+C9+C10) instead of =SUM(C8:C10) or =C8+C9+C10. The answer is correct, but the formula is not good: the + operators already did all the work, so the SUM() is superfluous.

Step through each formula the way Excel’s Evaluate Formula dialog does.

Avoid

    The additions finish first, so SUM receives a single number and has nothing left to add.

              Growth rate: two ways to say the same thing

              Let’s assume that the Sales Revenue in 2025 was $100 and the predicted Growth Rate per year is 50 % (0.5 in decimal terms). What is the predicted Sales Revenue in 2026?

              Sales 2025
              $100
              50 %
              Both methods move together, at every rate.

              Method 1

              Sales 2026 = Sales 2025 + Sales 2025 × Growth Rate

              Method 2 — mathematically equivalent, used in today’s class

              Sales 2026 = Sales 2025 × (1 + Growth Rate)

              On the slide the formula reads =B10*(1+$B$6). In this year’s workbook the same idea lands in C14 =B14*(1+$B$7) — the growth rate has its own cell, and the reference to it is absolute.

              LOOKUP Functions

              LOOKUPs — VLOOKUP & HLOOKUP

              Vertical & Horizontal Lookup …are functions to retrieve a value matching a specified condition from a table by searching a row (HLOOKUP) or a column (VLOOKUP).

              VLOOKUP — vertical

              Searches down the first column of the table, then returns a value from a column further right.

              =VLOOKUP(lookup_value, table_array,
                column_index_num, [range_lookup])

              HLOOKUP — horizontal

              Searches across the first row of the table, then returns a value from a row further down.

              =HLOOKUP(lookup_value, table_array,
                row_index_num, [range_lookup])

              In other words: the value you are looking for, the range containing it, which column (or row) of that range holds the answer, and approximate match (TRUE) or exact match (FALSE).

              LOOKUP Functions

              The fourth argument: TRUE or FALSE

              The last argument decides what counts as a match. FALSE wants the value exactly; TRUE takes the largest value that is still less than or equal to it — which is how a score turns into a letter grade.

              67 Drag through the boundaries — 59 to 60, 92 to 93 — and watch the band change.

              Approximate match — TRUE

              =VLOOKUP(C4,$H$4:$I$13,2,TRUE)

              Exact match — FALSE

              =VLOOKUP(C4,$H$4:$I$13,2,FALSE)

              The lookup column has to be sorted ascending for TRUE to work. The grade table in the workbook is: 0, 60, 70, 73, 77, 80, 83, 87, 90, 93.

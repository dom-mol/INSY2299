Absolute and Relative References

Cell references: relative, absolute, or both

Relative reference

=B2

Auto-adjusts the reference cell based on the new position (when copied/dragged).

Absolute reference

=$B$1

The reference cell stays fixed (when copied/dragged).

Absolute & relative

=B2*$B$1

B2 auto-adjusts while $B$1 stays fixed (when copied/dragged).

RECAP: SUM function

The SUM function adds values. You can add cell references or ranges or a mix of both.

=SUM(number1Required: a cell reference like SUM(C6), or a cell range like SUM(C2:C8),[number2], …Optional: other cell references or ranges, e.g. SUM(C2:C8,C16:C22))

COUNT counts numbers, COUNTA counts anything

The COUNT function is used to count the number of cells in a range that contain numbers. COUNT(value1, [value2], …): the first range is required, more ranges are optional, e.g. COUNT(C2:C8,C16:C22).

IF function

IF is used to make a conditional calculation, based on criteria that must be defined (= logical tests) by the analyst, and leads to either a “true” or a “false” option.

=IF(C2="Yes"Logical test,1True value, based on test,2False value, based on test)

Example 1 — returns a number

D2 =IF(C2="Yes",1,2)

Example 2 — returns text

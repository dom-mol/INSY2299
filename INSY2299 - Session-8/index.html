  1. Current Month Target: Previous Month Tickets increased by the Target Percentage (B8).

  3. Tickets Needed to Reach Target: Current Month Target − Current Month Tickets.

Safety and limitations

Why “trusted files only”?

A spreadsheet can hide instructions in its content (a prompt injection) that try to trick Claude.

Notes for reviewers

Inputs (current values)

    Business definition

    New function: SUMIFS

    =SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2, …)

    Adds the cells in sum_range only on rows where every condition is true. Each condition is a range plus what it must match; all ranges cover the same rows.

    C22 reads: add Units on rows where Product ID = A22 and Date is ≥ B5 and ≤ B6. ">="&$B$5 joins the operator to the input cell, so the period is not typed into the formula.

    The $ signs lock the Sales ranges and dates; $A22 moves down a row, so the same formula fills C23:C28 for the other products.

    One condition only? =SUMIF(range, criterion, sum_range): note the sum range comes last in SUMIF but first in SUMIFS.

          Multidimensional Data Cubes

          Multidimensional data cubes – the concept behind pivot tables

          Definition

          • Data Cube: stores data in multiple dimensions for fast analysis
          • Pivot Table: tool in Excel* that lets you explore and summarize cube data interactively

          Key features

          • Dimensions: categories such as time, region, product
          • Measures: quantitative values to analyze, e.g., sales, quantity

          How they connect

          • Data cubes organize the information
          • Pivot tables let users pivot dimensions into rows, columns, or filters to view it differently

          Benefits

          • Speed: pre-aggregated data for quick analysis
          • Flexibility: explore from different perspectives and granularities
          • Insight: discover patterns and trends in large datasets

          * And related tools

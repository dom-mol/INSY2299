Question: transaction_id contains digits. Why is it not a numeric measure?

It labels a transaction; it does not measure anything. Adding or averaging IDs gives a number with no meaning, so treat it as an identifier (text).

      Formulas & Excel Applications

      Basic Arithmetic in Excel – “PEMDAS”

      Excel uses standard “PEMDAS” order of operations for arithmetic: “Parentheses, Exponents, Multiplication and Division, and Addition and Subtraction”.

      5Parentheses"(6-3)"
      6Exponents - use caret"^"
      7Multiplication - use asterisk"*"
      8Division - use slash"/"
      9Addition"+"
      10Subtraction"-"

      For example, “six squared” is 6^2; “square root of six” is 6^(.5). * and / share a rank and go left to right; so do + and −.

      Assume we want (6-3)(4+2) = 18
